# Draft plan

Scaffolds a PR for a new delivery plan.

Cuts a `plan/<slug>` branch from `main`, prepares a fresh plan from the
template, and opens a pull request in a draft state.

Sets the status to `DRAFT`.

## How to invoke

> Draft plan

> Draft checkout hardening.

## Recommended models

A mid-tier model with strong prose output is best suited to this skill. The
scaffolding is mechanical, but capturing the shape of the work requires a bit
more effort.
