# Roadmap

This is a forward-looking, ordered view of active milestones.

The roadmap changes shape frequently. It is a single, living document, edited in
place. There is no other content in this directory besides this one file.

A milestone appears here for as long as it is `DRAFT` or `ACTIVE`. Once
every plan within the scope of a milestone is settled, the milestone itself
transitions to `DONE` (or `ABANDONED`) and it is moved from here to the log of
[past milestone's reached](../milestones/INDEX.md).
